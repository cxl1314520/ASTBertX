# ASTBertX: Sequence–Structure Semantic Fusion for Multilingual Exploit Type Identification

> **ASTBertX** (AST + BERT + XGBoost) is a multilingual exploit script detection and classification framework that fuses **sequence semantics** (GraphCodeBERT) with **structural semantics** (AST-GATv2) for fine-grained exploit type identification.

---

## 📖 Overview

Fine-grained detection of multilingual and multi-type exploit scripts has rarely been systematically investigated. ASTBertX addresses this gap by integrating two complementary representations of source code:

- **Sequence Semantics**: Extracted by the pre-trained [GraphCodeBERT](https://github.com/microsoft/CodeBERT) model via masked mean pooling
- **Structural Semantics**: Extracted by an enhanced GATv2 graph neural network operating on semantic-enriched Abstract Syntax Trees (ASTs) generated by [Tree-sitter](https://tree-sitter.github.io/)

The two representations are projected into a unified latent space via a two-stage training framework, and fed into an **XGBoost** classifier to produce exploit-type predictions.


## 🗂️ Dataset: Exploit-DB-EX

We construct **Exploit-DB-EX**, a multilingual multi-type exploit script dataset based on [Exploit-DB](https://www.exploit-db.com/). The dataset covers multiple programming languages and four major exploit categories compiled from the Exploit-DB database based on vulnerability tags.

| Category | Languages |
|----------|-----------|
| Benign | Python, C, Ruby, HTML, PHP |
| Overflow | Python, Perl, C, Ruby, HTML, PHP |
| Injection | Python, Perl, C, Ruby, HTML, PHP |
| Denial of Service | Python, Perl, C, Ruby, HTML, PHP |
| File Path | Python, Perl, C, Ruby, HTML, PHP |

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/cxl1314520/ASTBertX.git
cd ASTBertX/BERTAST

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# Install dependencies
pip install torch torchvision torchaudio
pip install transformers torch-geometric xgboost scikit-learn
pip install tree-sitter matplotlib seaborn tqdm joblib
```

### Download Pre-trained Models

Download the following models and place them under `LocalModel/`:

- [GraphCodeBERT](https://huggingface.co/microsoft/graphcodebert-base) → `LocalModel/graphcodebert-base/`
- [CodeBERT](https://huggingface.co/microsoft/codebert-base) → `LocalModel/code_bert/`

```python
from huggingface_hub import snapshot_download

snapshot_download(
    "microsoft/graphcodebert-base",
    local_dir="LocalModel/graphcodebert-base"
)
```

## 🚀 Usage

### Step 1: Prepare Dataset

```bash
# Download dataset from Hugging Face
python -c "
from datasets import load_dataset
ds = load_dataset('wwe123/Exploit-DB-EX')
"
```

### Step 2: Extract GraphCodeBERT Features

```bash
python bert/train_bert_mlp.py
# Output: bert/graphcodebert_mean.jsonl
```

### Step 3: Extract AST-GATv2 Features

```bash
python ast/AST.py
# Output: ast/ast_features.jsonl
```

### Step 4: Train Fusion Model

```bash
python shellast.py
# Output: output/fusion_model.pt
#         output/fusion_enhanced_concat_xgb.pkl
```

### Step 5: Evaluate

Results are automatically saved to `output/` including:
- Classification report (`.txt`)
- Confusion matrix (`.png`)
- Language × category accuracy breakdown (`.csv`)
